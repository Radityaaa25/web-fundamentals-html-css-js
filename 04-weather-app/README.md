# ☁️ SkyCast — Simple Weather App

**SkyCast** adalah project keempat dalam **Challenge Ngoding 55 Hari** (Day 7 & 8).
Project ini berfokus pada pengambilan data cuaca secara **Real-Time** menggunakan **OpenWeatherMap API**.

Ini adalah project pertama yang melibatkan komunikasi dengan server eksternal (Fetch API).

---

## 🎯 Tujuan Belajar
- Memahami konsep **API (Application Programming Interface)**.
- Belajar menggunakan **Fetch API** (`fetch()`) di JavaScript.
- Belajar menangani **Asynchronous JavaScript** (`async/await`).
- Menampilkan data JSON dari server ke tampilan HTML (DOM Manipulation).
- Error Handling (Misal: Kota tidak ditemukan).
