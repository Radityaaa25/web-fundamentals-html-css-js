# Pomodoro Timer App — Web Fundamentals Project

Pomodoro Timer App adalah mini project kedua dalam **Project Challenge Ngoding 55 Hari**.  
Project ini berfokus pada pembuatan **timer kerja berbasis metode Pomodoro** menggunakan **HTML, CSS, dan JavaScript (Vanilla)** tanpa framework.

Project ini bertujuan melatih pemahaman **time-based logic**, **DOM manipulation**, dan **state management sederhana** di JavaScript.

---

## 🎯 Tujuan Project
- Memahami struktur HTML untuk aplikasi timer
- Membuat UI sederhana dan fokus
- Mempelajari logika waktu menggunakan JavaScript
- Menggunakan `setInterval` dan `clearInterval`
- Melatih kontrol state (start, pause, reset)
