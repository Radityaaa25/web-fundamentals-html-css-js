# 👨‍💻 Personal Portfolio Website

**Portfolio Website** adalah project final (Day 12-14) dalam **Challenge Ngoding 55 Hari**.
Website ini berfungsi sebagai etalase untuk menampilkan seluruh project yang telah dikerjakan (Todo App, Weather App, dll).

Project ini menggabungkan semua ilmu yang dipelajari: HTML Semantik, CSS Flexbox/Grid, Responsive Design, dan JavaScript DOM.

---

## 🎯 Tujuan Belajar
- Membangun halaman web yang lengkap dan profesional.
- Membuat navigasi antar-halaman (internal links).
- Menerapkan **Smooth Scrolling** dan navigasi responsif.
- Menampilkan galeri project dengan Grid Layout.
