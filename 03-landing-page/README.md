# 🎧 Zenith Audio - Product Landing Page

**Zenith Audio** adalah sebuah Landing Page (Halaman Penawaran) untuk produk headphone wireless premium. Project ini merupakan bagian dari tantangan **Challenge Ngoding 55 Hari** (Day 5 & 6).

Fokus utama project ini adalah membangun struktur HTML yang **Semantic** (mudah dibaca mesin pencari/Google) dan layout yang **Responsif** (bagus di HP dan Laptop) tanpa bergantung pada framework CSS berat.

🛠️ Tech Stack & Konsep Baru

1. HTML5 Semantic
Kita tidak lagi hanya menggunakan <div>. Kita belajar menggunakan tag yang memiliki arti:

<header>: Bagian kepala website.

<nav>: Area navigasi/menu link.

<main>: Pembungkus konten utama.

<section>: Bab-bab dalam halaman (Hero, Features, Contact).

<article>: Konten yang berdiri sendiri (seperti kartu produk/fitur).

<footer>: Kaki website.

2. CSS Flexbox (Day 6)
Teknik modern untuk mengatur tata letak (layout) tanpa ribet pakai float.

display: flex;

justify-content: space-between;

align-items: center;
