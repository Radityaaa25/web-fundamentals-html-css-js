# Todo App — Web Fundamentals Project

Todo App adalah mini project pertama dalam **Project Challenge 55 Hari** yang bertujuan untuk melatih dasar-dasar web programming menggunakan **HTML, CSS, dan JavaScript (Vanilla)**.

Project ini difokuskan pada pembuatan struktur yang rapi, UI sederhana, serta penerapan logika dasar JavaScript.

---

## 🎯 Tujuan Project
- Memahami struktur HTML5 yang semantic
- Membuat UI sederhana namun usable
- Melatih manipulasi DOM dengan JavaScript
- Membiasakan workflow project kecil yang rapi

---

## 📁 Struktur Folder
01-todo-app/
├─ index.html
├─ css/
│ └─ style.css
├─ js/
│ └─ script.js
└─ README.md


> Struktur folder ini dibuat untuk memisahkan antara **struktur (HTML)**, **tampilan (CSS)**, dan **logika (JavaScript)**.

---

## ✨ Fitur
- Menampilkan daftar todo
- Menambahkan todo baru
- Menghapus todo
- Menandai todo sebagai selesai
- UI sederhana dan responsif

> *Catatan: Fitur dikembangkan secara bertahap selama beberapa hari.*

---

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)

Tanpa framework atau library tambahan.

---

## 🧠 Learning Outcome
Dari project ini, saya mempelajari:
- Cara menyusun HTML dengan elemen semantic
- Dasar styling menggunakan CSS
- Manipulasi DOM (querySelector, event listener)
- Mengelola state sederhana di JavaScript
- Struktur project web yang rapi dan scalable

---

## 🚀 Cara Menjalankan Project
1. Clone repository ini
2. Masuk ke folder `01-todo-app`
3. Buka file `index.html` di browser

Tidak membutuhkan setup tambahan.
