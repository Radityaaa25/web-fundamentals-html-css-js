# 💰 Expense Tracker

**Expense Tracker** adalah project kelima dalam **Challenge Ngoding 55 Hari** (Day 9-11).
Aplikasi ini berfungsi untuk mencatat pemasukan dan pengeluaran pribadi, serta menghitung saldo otomatis.

Project ini melatih logika **Array Methods** (`map`, `filter`, `reduce`) dan penyimpanan data permanen di browser (**LocalStorage**).

---

## 🎯 Tujuan Belajar
- Memahami manipulasi Array yang kompleks di JavaScript.
- Menggunakan **LocalStorage** agar data tidak hilang saat direfresh.
- Membuat fitur **CRUD** (Create, Read, Update, Delete) sederhana.
- Memformat angka menjadi format mata uang (IDR/Rupiah).
